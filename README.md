# PastyType

PastyType is a lightweight desktop application that simulates keyboard typing from user-provided text.

Instead of pasting text, PastyType types it character by character into the currently focused application. This makes it useful for repetitive data entry, demonstrations, testing, accessibility workflows, and situations where manual typing is impractical.

## Features

* Paste any text into the editor.
* Adjustable typing speed.
* Countdown before typing starts.
* Preserves indentation and formatting.
* Emergency stop while typing.
* Simple desktop interface.
* Windows executable planned.

## How it Works

1. Paste your text into PastyType.
2. Choose a typing speed.
3. Set the countdown.
4. Click **Start Typing**.
5. Focus the destination application before the countdown finishes.
6. PastyType types the text automatically.
